# Object Detection and Tracking

This project was developed as part of my CodeAlpha Artificial Intelligence Internship.

## About the Project

This project detects objects in real time using a webcam and tracks them across video frames.

## Technologies Used

- Python
- YOLO
- OpenCV
- ByteTrack

## Features

- Real-time object detection
- Object tracking
- Webcam-based video processing
- Tracking IDs for detected objects

## How to Run

First, install the required libraries:

pip install -r requirements.txt

Then run the program:

python object_tracking.py

Press **Q** to stop the program.
