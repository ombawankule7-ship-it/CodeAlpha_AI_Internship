# AI FAQ Chatbot

This project was developed as part of my CodeAlpha Artificial Intelligence Internship.

## About the Project

An AI-based FAQ chatbot that uses NLP techniques to find the most relevant answer to a user's question.

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- TF-IDF
- Cosine Similarity

## How to Run

Install the required libraries:

pip install -r requirements.txt

Then run:

streamlit run app.py
